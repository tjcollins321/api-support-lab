# Ten-ticket evaluation baseline

This is the unchanged reviewed report from the first ten-ticket live pass on
2026-10-22 in America/New_York. All ten tickets were attempted once: **6/10
agreement**, one operational timeout, and three expectation mismatches. Nine
drafts were produced; T-006 timed out with no draft, and T-007 did not ask for
the SDK version.

The baseline demonstrates that ten tickets are implemented and evaluation records
successes and failures. It does not establish full acceptance or reliability.
Human approval remains required before using any draft. The original score and
manual findings are frozen here; later scorer revisions must report new scores
separately and cannot replace this report.

The reviewed report includes synthetic tickets' result extracts, settings/versions,
available usage, tool retrievals, and manual notes. Before selection, the captures
passed exact-credential/pattern, allowlist, settings, and qualitative review. The
source remains under ignored `artifacts/evaluation/ten-ticket-live-20261022T235856Z/`.
No raw environment, credential, or unreviewed log is selected.

The pass recorded 23 model responses and one timed-out attempt. Available usage
was 34,989 input and 3,239 output tokens (38,228 total), with 16,359 cached input
and 77 reasoning output tokens. Known usage at standard rates was about $0.07;
the timeout's processing/cost and actual billed charges remain unknown.
